# 123云盘助手 (Pan123Pilot)

为 **MoviePilot V3** 深度定制的 123 云盘自动化上传、状态回写与做种清理插件。实现全自动化影视闭环链路：

> **qBittorrent 下载完成** → **MoviePilot 整理刮削** → **Pan123Pilot 零流量 SHA1 秒传** → **qBittorrent 标签流转回写** → **满足做种 H&R 规则后自动清理本地与种子** → **MoviePilot 系统渠道消息推送**

---

## 🌟 主要功能特性

1. **影视目录多级级联同步 (1:1 还原 Emby 媒体库)**：
   - 支持指定本地媒体库根路径（如 `/video` 或 `/media`），自动计算整理后媒体的相对目录层级。
   - 自动在 123 云盘中递归检索与创建对应各级子目录（如 `/video/emby-movies/国产电影/流浪地球 (2019)`），并附带内存缓存池，避免重复调用 API。
   - 保证 123 云盘上的目录树形结构与本地 Emby / Jellyfin 媒体库 1:1 精准对应。
2. **SHA1 零流量秒传优先**：
   - 监听 MoviePilot 整理刮削完成事件，自动提取新生成文件。
   - 分块流式计算 SHA1 和 MD5（内存友好、对硬盘友好，一个文件终身仅计算一次）。
   - 优先通过 123 开放平台接口进行 SHA1 秒传，命中后瞬间完成，**完全不消耗家庭上行带宽**。
3. **秒传失败定时重试与真实上传兜底**：
   - 秒传未命中时，自动放入排队队列，按设定间隔定时重新尝试 SHA1 校验（等待云端其他用户转存以触发秒传）。
   - 可自定义最大重试次数（默认 10 次）。达到设定上限后，可自动无缝切换为 V2 分片断点真实上传。
4. **qBittorrent 系统下载器下拉直选 (免重复输入密码)**：
   - 深度集成 MoviePilot 下载器管理机制，配置表单动态扫描系统已绑定的 QB 客户端。
   - 用户只需下拉点选，后台自动复用 IP、端口与账号密码，无需繁琐二次手动配置（亦支持保留手动配置模式）。
   - 自动在 qBittorrent 中定位对应种子并更新状态标签：
     - `123_待处理`：已整理刮削，等待哈希计算。
     - `123_上传中`：正在计算哈希或正在进行分片真实上传。
     - `123_待重试`：SHA1 秒传未命中，处于等待重试队列。
     - `123_秒传失败`：达到最大重试次数。
     - `123_已上传`：123 云盘已同步完毕（秒传成功或真实上传完成）。
5. **Symedia Webhook 自动化联动 (302直链与.strm秒级生成)**：
   - 原生兼容 **CloudDrive2 (CD2) 文件系统事件规范**（`/api/v1/webhook/clouddrive2/file_notify`）。
   - 文件同步/秒传成功瞬间，自动组装规范 JSON 报文向 Symedia 发送 `create` 文件事件。
   - Symedia 收到通知后立即为对应媒体文件生成 `.strm`，打通 **“转存 123 云盘 → strm 生成 → Emby 302 秒播”** 全链路。
6. **做种达标自动安全清理 (H&R 规则)**：
   - 只有在云端确认同步完毕（`123_已上传`）的前提下，才会进入清理判定。
   - 支持自定义**最低做种时间**（如 48 小时）与**最低分享率**（如 2.0）。
   - 达标后自动安全清理 qBittorrent 种子、源数据文件以及 MoviePilot 本地硬链接，并自动向上递归清理空目录。
7. **MoviePilot 系统消息渠道通知联动**：
   - 深度集成 MoviePilot 官方通知体系（微信、Telegram、Bark 等通知渠道）。
   - 关键节点自动推送消息卡片：秒传成功通知、做种达标自动清理通知、同步异常报警。
8. **官方开放平台 Token 自动保活**：
   - 基于 Client ID 与 Client Secret，自动获取并在过期前 5 分钟自动刷新 Access Token，免除人工频繁配置 Token 的烦恼。
9. **历史已整理媒体全量扫描补录与精确种子关联 (v1.2.0)**：
   - 支持一键扫描本地已整理的影视库（如 `/video`），自动排查未同步的视频文件。
   - **智能种子 Hash 逆向关联**：直连 MoviePilot `transferhistory` 整理历史表，毫秒级反查出原种子的 `download_hash` 与下载源路径；对无整理历史的孤儿文件，自动模糊匹配 qBittorrent 中对应的种子。
   - 补录后自动回写 `123_待处理` 标签并立即触发后台流式计算 SHA1 发起秒传与真实上传，完美解决“插件安装前已有历史影视文件无法上传”的痛点。

   - 点击顶部标签栏的 **`Application`（应用）**；
   - 在左侧展开 **`Local Storage`（本地存储空间）** → 点击 **`https://www.123pan.com`**；

## 📖 【实战配置示例】端到端全自动直链闭环搭建

以最常见的 Docker / NAS 环境为例，手把手教您如何配置各组件：

### 场景设定
- **本地影视硬链接库**：`/video`（对应容器内 `/video/emby-movies/国产电影/xxx.mkv`）
- **123 云盘**：在 123 云盘根目录下新建了名为 `video` 的文件夹（其文件夹 ID 为 `14663228`）
- **Symedia 挂载点**：Symedia 通过 CD2 或 CloudNAS 挂载 123 云盘，其路径为 `/CloudNAS/123/video`
- **下载器**：MoviePilot 中已经添加了名称为 `QB-PT` 的下载器

### 插件配置填写指引
1. **凭证设置**：
   - `Client ID` / `Client Secret`：填入 123 开放平台生成的字符串。
2. **媒体库与级联设置**：
   - `本地媒体库根路径`：填写 `/video`
   - `123 云盘根目录 ID`：填写 `14663228`
   - `启用目录级联同步`：**开启**
3. **qBittorrent 设置**：
   - `选择已配置的 qBittorrent`：下拉选中 `【系统下载器】QB-PT (...)`
4. **Symedia 设置**：
   - `启用 Symedia Webhook`：**开启**
   - `Symedia 服务地址`：填写 `http://192.168.1.50:8095`（或外网地址）
   - `Symedia 挂载前缀`：填写 `/CloudNAS/123/video`
5. **做种清理**：
   - `启用做种达标清理`：**开启**
   - `最低做种时间`：`48`

## 🛠 使用方式与工作周期

1. **自动触发**：
   - 用户无需手动触发。MoviePilot 每次完成刮削整理时，插件将自动捕获新生成文件并启动调度。
2. **定时服务**：
   - **秒传重试服务**：按照设定的 `retry_interval` 周期执行，自动重新校验重试队列中的任务。
   - **安全清理服务**：每隔 60 分钟巡检一次已完成任务，判定做种达标情况并执行清理。
3. **手动 API 接口**：
   - `GET /api/plugins/pan123pilot/tasks`：查询最近 50 条任务的流转详情。
   - `POST /api/plugins/pan123pilot/trigger_retry`：手动立即触发一次秒传重试。
   - `POST /api/plugins/pan123pilot/trigger_cleanup`：手动立即触发一次做种达标清理。
   - `POST /api/plugins/pan123pilot/scan_library`：手动扫描本地媒体库目录，补录未同步视频并即刻发起秒传检测。
   - `POST /api/plugins/pan123pilot/send_sms`：向手机号发送 123 官方短信验证码。
   - `POST /api/plugins/pan123pilot/verify_sms`：提交收到的短信验证码，完成登录并持久化保存 Token。
   - `GET /api/plugins/pan123pilot/test_auth`：测试当前配置的认证通道状态。
