# 123云盘助手 (Pan123Pilot)

为 **MoviePilot V3** 深度定制的 123 云盘自动化上传、状态回写与做种清理插件。实现全自动化影视闭环链路：

> **qBittorrent 下载完成** → **MoviePilot 整理刮削** → **Pan123Pilot 零流量 SHA1 秒传** → **qBittorrent 标签流转回写** → **满足做种 H&R 规则后自动清理本地与种子** → **MoviePilot 系统渠道消息推送**

---

## 🌟 主要功能特性

1. **SHA1 零流量秒传优先**：
   - 监听 MoviePilot 整理刮削完成事件，自动提取新生成文件。
   - 分块流式计算 SHA1 和 MD5（内存友好、对硬盘友好，一个文件终身仅计算一次）。
   - 优先通过 123 开放平台接口进行 SHA1 秒传，命中后瞬间完成，**完全不消耗家庭上行带宽**。
2. **秒传失败定时重试与真实上传兜底**：
   - 秒传未命中时，自动放入排队队列，按设定间隔定时重新尝试 SHA1 校验（等待云端其他用户转存以触发秒传）。
   - 可自定义最大重试次数（默认 10 次）。达到设定上限后，可自动无缝切换为 V2 分片断点真实上传。
3. **qBittorrent 标签实时流转回写**：
   - 自动在 qBittorrent 中定位对应种子并更新状态标签：
     - `123_待处理`：已整理刮削，等待哈希计算。
     - `123_上传中`：正在计算哈希或正在进行分片真实上传。
     - `123_待重试`：SHA1 秒传未命中，处于等待重试队列。
     - `123_秒传失败`：达到最大重试次数。
     - `123_已上传`：123 云盘已同步完毕（秒传成功或真实上传完成）。
4. **做种达标自动安全清理 (H&R 规则)**：
   - 只有在云端确认同步完毕（`123_已上传`）的前提下，才会进入清理判定。
   - 支持自定义**最低做种时间**（如 48 小时）与**最低分享率**（如 2.0）。
   - 达标后自动安全清理 qBittorrent 种子、源数据文件以及 MoviePilot 本地硬链接。
5. **MoviePilot 系统消息渠道通知联动**：
   - 深度集成 MoviePilot 官方通知体系（微信、Telegram、Bark 等通知渠道）。
   - 关键节点自动推送消息卡片：秒传成功通知、做种达标自动清理通知、同步异常报警。
6. **官方开放平台 Token 自动保活**：
   - 基于 Client ID 与 Client Secret，自动获取并在过期前 5 分钟自动刷新 Access Token，免除人工频繁配置 Token 的烦恼。

## 🔑 123 云盘 Client ID / Secret 申请指引 (个人免费自助秒批)

申请 123 开放平台凭证无需企业资质，个人开发者可在 2 分钟内自助开通：

1. **访问开放平台**：
   - 打开 [123云盘开放平台官网 (https://open.123pan.com/)](https://open.123pan.com/)。
2. **登录账号**：
   - 使用您平时的 123 云盘手机号/账号密码或扫码登录。
3. **进入开发者中心**：
   - 登录后点击右上角的 **「开发者中心」** 或进入控制台。
4. **创建自建应用**：
   - 在应用列表页点击 **「创建应用」**（应用类型选择自建应用/个人应用）。
   - 应用名称填写任意名称（如：`MoviePilot云盘同步`），应用简介简单填写即可。
5. **获取凭据**：
   - 提交创建后系统将**立即生成并展示** `Client ID` 和 `Client Secret`。
   - 将其复制并填写到本插件的 MoviePilot 配置页面对应输入框中即可。

## ⚙️ 配置项详细说明

在 MoviePilot 后台插件管理页面中，支持如下配置：

### 1. 123 云盘开放平台凭证
| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `enabled` | `False` | 是否启用本插件。 |
| `client_id` | 空 | 123 开放平台申请的应用 Client ID。 |
| `client_secret` | 空 | 123 开放平台申请的应用 Client Secret。 |
| `target_parent_file_id` | `0` | 上传到 123 云盘的目标目录 ID（`parentFileID`），根目录填 0。 |

### 2. 秒传与重试策略
| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `retry_interval` | `30` | 秒传未命中时的定时重试检查间隔（单位：分钟）。 |
| `max_retry_count` | `10` | 秒传最大重试次数。 |
| `enable_real_upload` | `True` | 达到最大重试次数后，是否启动真实分片本地上传兜底。 |

### 3. qBittorrent 联动与标签设置
| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `qb_host` | 空 | qBittorrent WebUI 访问地址（留空则不联动或使用主程序默认下载器）。 |
| `qb_username` | 空 | qBittorrent 登录用户名。 |
| `qb_password` | 空 | qBittorrent 登录密码。 |
| `tag_pending` | `123_待处理` | 加入处理队列时的种子标签。 |
| `tag_uploading` | `123_上传中` | 处理与上传中的种子标签。 |
| `tag_retrying` | `123_待重试` | 秒传重试队列中的种子标签。 |
| `tag_failed` | `123_秒传失败` | 秒传失败时的种子标签。 |
| `tag_completed` | `123_已上传` | 同步完成时的种子标签。 |

### 4. 做种达标自动清理 (H&R 规则)
| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `enable_auto_cleanup` | `False` | 是否开启做种达标后的自动清理。 |
| `min_seed_time` | `48.0` | 种子最低做种时长（单位：小时）。 |
| `min_seed_ratio` | `2.0` | 种子最低做种分享率（Ratio）。 |
| `delete_torrent_file` | `True` | 清理时是否从 qBittorrent 中删除种子和源数据。 |
| `delete_hardlink_file` | `True` | 清理时是否删除 MoviePilot 整理刮削的本地硬链接。 |

### 5. MoviePilot 系统消息通知
| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `notify_enabled` | `True` | 是否启用 MoviePilot 系统渠道消息推送。 |
| `notify_on_upload` | `True` | 秒传或真实上传成功时发送通知。 |
| `notify_on_cleanup` | `True` | 满足做种达标并完成自动清理后发送通知。 |
| `notify_on_failed` | `True` | 同步失败或重试超限时发送报警通知。 |

## 🛠 使用方式与工作周期

1. **自动触发**：
   - 用户无需手动触发。MoviePilot 每次完成刮削整理时，插件将自动捕获新生成文件并启动调度。
2. **定时服务**：
   - **秒传重试服务**：按照设定的 `retry_interval` 周期执行，自动重新校验重试队列中的任务。
   - **安全清理服务**：每隔 60 分钟巡检一次已完成任务，判定做种达标情况并执行清理。
3. **手动 API 接口**：
   - `GET /api/plugins/pan123pilot/tasks`：查询最近 50 条任务的流转详情。
   - `POST /api/plugins/pan123pilot/trigger_retry`：手动立即触发一次秒传重试。
   - `POST /api/plugins/pan123pilot/trigger_cleanup`：手动立即触发一次做种达标清理。
